# Festa-Facil


## Problema:
Organizar uma festa exige controlar várias informações ao mesmo tempo, como convidados, tarefas, orçamento, decoração e compras.

## Publico:
Pessoas que organizam festas e pequenos eventos, como:
Aniversários.
Formaturas.
Confraternizações.
Festas familiares.
Pequenos eventos.


## Solução:
O Festa-Fácil será uma ferramenta para auxiliar no planejamento de festas.
A proposta é permitir que o usuário organize:
Lista de convidados.
Tarefas.
Orçamento.
Decoração.
Lista de compras.


## Objetivo da Sprint:
Criar e testar uma primeira versão simples do FestaFácil, permitindo organizar convidados, tarefas e orçamento de uma festa.


## Tarefas:
Entrevistar um possível usuário.
Identificar as principais necessidades.
Definir principais tarefas.
